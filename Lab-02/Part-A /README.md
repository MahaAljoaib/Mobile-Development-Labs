# Lab 02 - Part A

This section contains the Kotlin fundamentals exercises for Lab 02.

## Tasks Included

- Task 1: Variables and string templates
- Task 2: Functions, default values, and named arguments
- Task 3: Conditional expressions using `if` and `when`
- Task 4: Null safety
- Task 5: Data classes and collections

## Implementation

Tasks 1–5 are combined in a single Kotlin file:

`Tasks1-5.kt`

The file includes all required functions and a `main()` function to run the tasks.

Kotlin
